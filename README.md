
# 抖音批量下载器
<img width="1182" height="812" alt="bb487f2a-a851-4e9d-a5a3-dc219b692614" src="https://github.com/user-attachments/assets/c6c6289e-ded5-4c6b-b001-3c598a7fce6a" />
一个面向 Windows 的桌面工具，用于批量采集抖音账号主页作品，并将视频下载为本地 MP4 文件。项目使用 Python、PySide6 和 QtWebEngine 构建，支持登录态持久化、批量采集、最高画质下载、暂停与断点续传，以及音视频流合并。

> 当前版本：`v1.3.2`

百度网盘：链接: https://pan.baidu.com/s/1vcIirgXVSTbv_ZNq12d4HQ?pwd=8888 提取码: 8888

## 功能特性

- 内置浏览器扫码登录抖音，登录态保存在本机，下次启动可继续使用。
- 从主播主页采集全部作品，也支持直接导入视频链接或视频 ID。
- 采集数量会参考主页显示的作品数，并对可能不完整的结果进行提示。
- 支持最高、较高和标准三档画质，以及自定义保存目录。
- 支持暂停、继续、停止、失败项重试和跳过已存在文件。
- 使用 HTTP Range 实现断点续传，临时文件下载完成后自动校验并改名。
- 内置 `ffmpeg.exe`，可合并抖音提供的分离音频和视频流。
- 默认低并发，降低触发平台限流或验证码的概率。

## 环境要求

- Windows 10 或更高版本
- Python 3.10 及以上版本
- 可访问抖音网页的网络环境
- 推荐至少 4 GB 可用内存和充足的磁盘空间

项目当前没有单独的 `requirements.txt`，依赖版本以交接说明和构建环境为准：

- `PySide6==6.11.2`
- `PyInstaller==6.22.2`

## 安装与运行

在项目根目录打开 PowerShell，执行：

```powershell
Set-Location .\源码
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install PySide6==6.11.2 PyInstaller==6.22.2
python main.py
```

如果 PowerShell 禁止激活虚拟环境，也可以直接使用虚拟环境中的 Python：

```powershell
Set-Location .\源码
.\.venv\Scripts\python.exe main.py
```

## 使用说明

### 1. 登录

1. 启动程序后进入“浏览器 · 登录”页面。
2. 点击抖音页面右上角的登录入口，使用抖音 App 扫码登录。
3. 登录态会保存到本机应用数据目录，下次启动通常无需重复扫码。

程序也提供从本机 Chrome / Edge 尝试导入 Cookie、手动粘贴 Cookie 的方式。由于新版浏览器可能使用应用绑定加密，自动导入失败时请使用扫码登录。

### 2. 采集视频

在“批量下载”页面选择一种方式：

- 将主播主页链接粘贴到输入框，点击“一键下载该主播全部视频”。该操作会采集并全选列表，但需要再次点击“开始下载”。
- 点击“仅抓取列表”，先检查列表内容，再手动勾选需要的视频。
- 在浏览器页打开主播主页后，点击“抓取浏览器当前页”。
- 点击“导入视频链接”，按每行一个的格式粘贴视频链接或纯视频 ID。

采集窗口需要保持打开，直接关闭会中止采集。若采集数量少于主页显示数量，可以再次采集，已加入列表的视频不会重复添加。

### 3. 下载视频

1. 选择保存目录和画质。
2. 勾选需要下载的视频，或使用全选、反选。
3. 点击“开始下载”。
4. 下载过程中可以暂停并继续，或重试失败的项目。

默认保存目录为当前 Windows 用户桌面下的 `抖音视频` 文件夹。下载中的文件会暂时使用 `.part.mp4` 后缀，完成并校验成功后才会变为正式文件。

如果出现“需要人工验证”或连续解析失败，点击“去验证”，在内置浏览器中完成滑块验证，然后返回下载页面继续任务。适当降低解析和下载并发也有助于减少限流。

## 编译打包

先完成依赖安装，并在 `源码` 目录执行冒烟测试：

```powershell
Set-Location .\源码
python tools\smoke_ui.py
```

冒烟测试通过后执行打包：

```powershell
python tools\build.py
```

打包产物默认位于：

```text
源码\dist\抖音批量下载器.exe
```

构建脚本会自动包含程序图标和 `app\bin\ffmpeg.exe`。不要只使用简单的 `pyinstaller main.py` 替代构建脚本，否则可能缺少 QtWebEngine 组件、图标或 ffmpeg。

## 数据与隐私

应用数据默认保存在：

```text
%LOCALAPPDATA%\DouyinDownloader\
```

其中包括 QtWebEngine 浏览器 Profile、登录态备份、配置和运行日志。不要将该目录中的 Cookie、`session.json` 或日志提交到公共代码仓库。设置页提供“打开数据目录”和“退出登录（清除本机登录信息）”操作。

## 开发注意事项

- 不要修改 `源码/app/config.py` 中的 `APP_NAME`，否则已有登录态和设置会被视为另一套数据。
- 解析器的 QtWebEngine 视图池需要复用，不能在每个视频后销毁并重新创建。
- 修改设置页帮助文本时，注意其中的 `%d` 格式化占位符。
- 平台可能返回验证码页面或限制访问，程序不会绕过验证码；请按页面提示人工完成验证。
